# Nota de Bienvenida de Obsidian

Nota predeterminada que Obsidian genera al crear un vault nuevo.

## Puntos clave
- Indica que el vault está vacío y listo para usar
- Sugiere crear notas, usar `[[enlaces wiki]]`, o probar el plugin [Importer](https://help.obsidian.md/Plugins/Importer)
- Recomienda borrar esta nota cuando el usuario se apropie del vault

## Relevancia
Fuente trivial usada como ejemplo de ingesta. No contiene conocimiento sustantivo.
