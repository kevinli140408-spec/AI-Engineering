# Obsidian

Editor de notas basado en archivos markdown locales. Usa `[[enlaces wiki]]` para conectar notas entre sí.

## Características relevantes
- Almacenamiento local (archivos .md en disco)
- Enlaces bidireccionales y vista de grafo
- Ecosistema de plugins: Importer, Dataview, Marp, Web Clipper
- Ideal como interfaz visual para este wiki (el LLM edita, el humano navega en Obsidian)
