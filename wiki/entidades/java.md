# Java (lenguaje)

Lenguaje de programación diseñado por técnicos de Sun Microsystems a mediados de los años 90, pensado desde el inicio para que sus programas fueran ejecutables en cualquier tipo de dispositivo (teléfonos, televisores, microondas). Al presentarse en público permitía crear pequeños programas ejecutables en navegadores web (los *applets*), lo que le dio un gran impulso inicial; con el tiempo se impuso sobre todo en el desarrollo de **aplicaciones web del lado del servidor**.

## Modelo de ejecución
Es un caso **híbrido** entre compilado e interpretado: el código fuente se compila a *bytecode* portable, que luego es interpretado (o compilado "justo a tiempo") por la Máquina Virtual de Java (JVM) en cada plataforma — el lema "escribe una vez, ejecuta en cualquier lugar". Ver la comparación completa de niveles de traducción en [[conceptos/lenguajes-de-programacion]].

## Comparación con Python
Es uno de los lenguajes de programación más utilizados en el mundo profesional, junto a un ecosistema muy amplio de bibliotecas y un entorno de desarrollo maduro. Sin embargo, programar en Java requiere más atención a los detalles y produce programas más extensos que su equivalente en [[entidades/python]] — el libro [[fuentes/introduccion-a-la-programacion-con-python-3]] lo usa como término de comparación constante para justificar el uso de Python como primer lenguaje de enseñanza, aunque ambos se enseñan en el primer curso de la UJI (Python primero, Java después).
