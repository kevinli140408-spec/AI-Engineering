# Tim Berners-Lee

Científico de la computación británico (n. 1955), creador de la **World Wide Web (WWW)** en 1989 mientras trabajaba en el **CERN** (Organización Europea para la Investigación Nuclear), en Suiza — ver contexto completo en [[conceptos/redes-y-web]].

## Contribución principal
Diseñó los tres pilares que hicieron posible la Web como sistema de información distribuido sobre Internet:
- **HTML** (HyperText Markup Language): lenguaje de marcado para estructurar y enlazar documentos.
- **HTTP** (HyperText Transfer Protocol): protocolo de comunicación cliente-servidor para transferir esos documentos.
- **URL** (Uniform Resource Locator): esquema de direccionamiento único para localizar cualquier recurso en la red.

Su motivación original era facilitar que investigadores del CERN compartieran documentos entre sí sin depender de un formato o ubicación física común — un problema que la arquitectura [[conceptos/redes-y-web|cliente-servidor]] resolvía de forma escalable.

## Legado
Fundó y dirige el **World Wide Web Consortium (W3C)**, el organismo que estandariza las tecnologías web (HTML, CSS, XML, entre otras), asegurando que la Web siguiera siendo un estándar abierto y no propietario. Es una figura de referencia obligada al estudiar el origen de Internet y la Web, tal como [[entidades/guido-van-rossum]] lo es para Python.
