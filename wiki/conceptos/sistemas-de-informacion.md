# Sistemas de Información

Un sistema de información es todo aquello que tenga diferentes componentes que funcionen para la recolección y almacenamiento de datos (utilice o no un programa informático) — no debe confundirse como sinónimo exclusivo de "sistema de información informático". Su objetivo principal es la **obtención de información** que luego se usa para tomar decisiones o predecir comportamientos/fenómenos.

## Elementos de un sistema de información

- **Personal**: recurso humano que recopila y organiza la información, y la carga en soportes materiales o plataformas virtuales.
- **Organización**: variables cualitativas o cuantitativas sobre hechos o fenómenos; una vez procesados los datos se convierten en información utilizable — ver [[conceptos/procesamiento-de-datos]].
- **Tecnología**: plataformas o software para almacenar y procesar los datos (un sistema de información puede también ser no digital, archivado en soportes físicos).

## Tecnología de la información (TI)

Combina medios y métodos de recopilación, procesamiento y transmisión de datos para obtener información nueva de calidad sobre el estado de un objeto, proceso o fenómeno, orientada a la toma de decisiones. Permite que las organizaciones sean más competitivas y se usa para gestión financiera, registros de empleados, pagos, compras y facturación.

## Clasificación según su ejecución gerencial

- **Sistemas de Procesamiento de Transacciones (TPS)**: recopilan información de las transacciones/funcionamiento de la organización (nivel gerencia operacional).
- **Sistemas de Información Ejecutiva (EIS)**: monitorizan variables gerenciales de un área específica (nivel alta gerencia).
- **Sistemas de Información Gerencial (MIS)**: contemplan la información general de la organización como un todo (nivel alta gerencia).
- **Sistemas de Soporte de Decisiones (DSS)**: procesan información intra y extra organizacional para apoyar la conducción de la empresa (nivel gerencia media).

## Clasificación según su modo de ejecución

- **Batch (por lotes)**: no interactúa directamente con el usuario; un operador agrupa trabajos similares en lotes (ej.: sistema de nómina, estados de cuenta bancarios, impresión de libros).
- **Online**: permite acceder e interactuar con bases de datos en tiempo real, sin esperar procesos de actualización.
- **En tiempo real**: componentes de hardware y software que responden a eventos dentro de límites de tiempo predecibles y específicos (control industrial, imágenes médicas, control de tráfico aéreo, robots).
