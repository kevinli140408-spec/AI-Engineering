# Pensamiento Computacional

Forma de **analizar problemas y diseñar soluciones de manera estructurada**, utilizando ideas y estrategias propias de la informática, sin necesidad de usar una computadora. Consiste en pensar como lo haría alguien que programa: dividir problemas, identificar patrones, diseñar pasos claros.

## Esquema Problema → Algoritmo → Programa

| Etapa | Pregunta clave |
|-------|---------------|
| **Problema** | ¿Qué se quiere resolver? |
| **[[conceptos/algoritmo|Algoritmo]]** | ¿Cómo se resuelve? (diseño de la solución) |
| **Programa** | ¿Cómo se escribe en un lenguaje de programación? |

## Análisis del problema (entender el problema)
1. **Objetivo**: ¿qué se quiere lograr?
2. **Entradas**: qué información es conocida o se pide al usuario (tipo de dato y cantidad).
3. **Salidas**: qué información se muestra y cuándo (tipo de dato y cantidad).
4. Requisitos, límites o restricciones adicionales.

## Estrategias de diseño
- **Top-Down**: de lo general a lo específico, descomponiendo en partes cada vez más pequeñas.
- **Bottom-Up**: resolver primero pequeños problemas y combinarlos en la solución completa.

## Modelo Entrada–Proceso–Salida
```
ENTRADA → PROCESO → SALIDA
"Lo conocido"   pasos a realizar   "Lo esperado"
```

## Ciclo completo de creación de un programa
Problema → Diseño de Algoritmo → Programa → **Verificar y Depurar** (con retroalimentación a cualquier etapa anterior si se detectan errores).
