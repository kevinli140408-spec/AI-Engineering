# Redes y la Web

Una **red** conecta varias computadoras entre sí para compartir recursos (impresoras, archivos, información). Se clasifican según su alcance:
- **LAN** (Local Area Network): red de área local (oficina, edificio).
- **WAN** (Wide Area Network): red de área amplia; Internet es la WAN más conocida.

## Modelos de comunicación
- **Cliente-servidor**: el **servidor** posee y comparte recursos; los **clientes** los solicitan. Es el modelo dominante, incluida la Web.
- **P2P (peer-to-peer)**: las computadoras colaboran entre sí sin un servidor central (p. ej. Napster, redes científicas distribuidas).

## Internet y la World Wide Web
La **WWW** (creada en 1989 por [[entidades/tim-berners-lee]] en el CERN) es un sistema de estándares para almacenar, recuperar y visualizar información mediante arquitectura cliente-servidor. Conceptos clave:
- **HTML**: lenguaje de marcado para páginas Web.
- **URL**: dirección única de una página Web.
- **Navegador (browser)**: interfaz para acceder a la Web.
- **XML**: lenguaje de marcado más flexible que HTML, sucesor para intercambio de datos estructurados.

## Web 2.0
Generación de la Web (término acuñado en 2004 por Tim O'Reilly) caracterizada por la participación activa del usuario: blogs, redes sociales, RSS, y tecnologías como **AJAX** (JavaScript + XML) que permiten actualizar páginas sin recargarlas.
