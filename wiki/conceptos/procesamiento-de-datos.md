# Procesamiento de Datos

Los **datos** son hechos (organizados o no) que pueden manipularse para volverse útiles y comprensibles, convirtiéndolos en **información**. Durante el procesamiento, los datos brutos se usan como entrada para producir información como salida, normalmente en forma de informes y otras herramientas analíticas — ver [[conceptos/teoria-de-la-informacion]].

## Cómo se procesan los datos

Para ser procesados por un ordenador, los datos primero deben convertirse a un formato legible por máquina. Una vez en formato digital, se les aplican procedimientos como:

Entrada de datos, captura de datos, tipos de datos, depuración de datos, integridad de datos, codificación (cifrado) de datos, transformación de datos, traducción de datos, resúmenes y agregación de datos, validación de datos, modelado de datos, análisis de datos (incluyendo análisis estadístico), visualización de datos, almacenamiento de datos, minería de datos e interpretación de datos.

El procesamiento puede realizarse mediante filtrado, análisis y visualización de datos, e incluso con algoritmos de aprendizaje automático (ver [[conceptos/inteligencia-artificial-organizacional]]), variando según la fuente de datos (base de datos, redes sociales, dispositivos conectados, etc.).

## La organización y los procesos

La organización se entiende como el conjunto de procesos y herramientas fundamentadas por la existencia de roles y funciones para alcanzar un objetivo — ver [[conceptos/organizacion-como-sistema]] y [[conceptos/proceso-proyecto-modelo]] para la distinción formal entre proceso, proyecto y modelo.
